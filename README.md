# 山西扣点 · 牌理练习器

纯前端（零依赖、离线可用）的**山西扣点（扣点点）**牌理分析与单机 AI 对战工具。手动输入与本地模拟，只用于练习与复盘——不读屏、不连接任何游戏、无实时提示。

**在线版：** https://aduoer.github.io/mahjong-koudian/
**本地版：** 直接用浏览器打开 `index.html` 即可（保持所有文件在同一目录）。

## 功能

### 分析（打哪张）
- 输入 14 张手牌（点选牌面，或记法如 `123456789m 234p 55s`）→ 按牌效给出出牌排序
- 13 张（未摸牌）时看听口与有效进张
- 已按扣点规则特殊处理：
  - 1~2 点不能胡：听口标"不能胡"且不计入有效张数
  - 3~5 点仅自摸（黄标）
  - 报听要求听口含 6 点以上；听口全在 6 点以下 = **死听**（不能报听、胡不了，红标）
- 支持副露 0~4 副；支持七小对

### 练习
- 随机发牌，点你想打的牌 → 与推荐对比（含累计一致率）

### 对战（单机模拟，本地推演）
- 我上桌：坐东家 vs 3 个 AI；或观战 4 个 AI 自动打
- AI 三种风格：**牌效型**（最大进张）/ **防守型**（有玩家报听时避开其点炮听口，最多降一档）/ **平衡型**（只在同档内避）——防守只看公开的报听听口
- AI 每打一张都写明理由；有玩家报听时，你手里会点炮的牌标红框
- 「连跑 20 局」：同一牌桌连打 20 局，比较各风格 AI 战绩

## 运行测试

```bash
node engine-test.js    # 牌理引擎自检
node sim-test.js       # 对战引擎压测（观战 150 局 + 人机 100 局 + 多风格 60 局）
node sim-ui-test.js    # 对战页 UI 冒烟测试（最小 DOM 桩）
```

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `engine.js` | 牌理引擎：向听/听口/出牌推荐（扣点点数规则） |
| `sim.js` | 单机对战引擎：发牌/摸打/碰/报听/胡牌判定 + 三种风格 AI |
| `sim-ui.js` | 对战页界面逻辑 |
| `index.html` | 页面入口（分析 / 练习 / 对战） |
| `*-test.js` | 自动测试 |
